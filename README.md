# Cost Analysis in Relation to Vehicle Brand
This analysis aims to use the provided database to understand how registered vehicle costs compare with global brand popularity.

## 🏁Objetive
Understand how the popularity of a vehicle brand affects vehicle costs, even over time, depending on the make and model.

## 🖥Technologies used
- **Python**: Pandas, plotly_express, streamlit
- **Jupyter Notebook**: Interactive environment for analysis.
- **CSV Dataset**: Contains user behavior data.

## 🔑Key Steps
1. **Data Description**:
   - Assessed the quality of the dataset and summarized its structure.
2. **Data Preprocessing**:
   - Handled missing values, corrected formatting issues, and removed duplicates.
3. **Hypothesis Testing**:
   - Compared user activity between cities and across different days of the week using statistical methods.
4. **Development of the web application dashboard**:
   - Creation of a website to present the results.

## 🥇🏆Results
The analysis confirms that:
- There is a direct relationship between the car brand and the price: the higher the price, the greater the popularity of the brand.
- No matter the model year, the brand still influences the cost of the vehicle.
